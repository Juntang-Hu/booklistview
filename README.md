# booklistview

##  專案簡介 
TSV檔案擷取系統😶‍🌫️😶‍🌫️😶‍🌫️

本專案是一個超強的 TSV 檔案讀取工具，能夠快速載入、解析並條列化展示 TSV 或 TXT 格式的單字庫資料，方便使用者瀏覽單字、音標與釋義
##  使用方式
點擊選單列的 File -> 開啟檔案，選取專案目錄或自訂的 TSV 單字檔，系統將自動解析並將「單字」、「音標」、「音檔路徑」與「解釋」完整呈現於下方的詳細列表中。最下方的狀態列亦會即時回報成功載入的單字總數量。
